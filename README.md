## Sobre mim

## Projetos e soluções

### Automação CMD Coleta

Desenvolvimento de uma solução para automatizar o processo de cadastro de **Contatos Assistenciais no CMD Coleta**.

O projeto envolve leitura e validação de dados, integração com serviços do ecossistema da saúde, construção de payloads, tratamento de erros, controle das execuções e automação do processo de cadastro.

**Tecnologias e conceitos:**

`Python` `APIs REST` `Automação` `Integração de Sistemas` `Processamento de Dados` `Excel` `Testes`

### Automação Conta Azul

Desenvolvimento de automações para processos financeiros utilizando **n8n, Python e integrações com o Conta Azul**.

O trabalho envolve integração entre sistemas, processamento de documentos e dados financeiros, automação de etapas operacionais e redução de tarefas manuais.

**Tecnologias e conceitos:**

`n8n` `Python` `Node.js` `APIs REST` `Automação Financeira` `Integrações`

### Guará Ouvidoria

Participação no desenvolvimento, em equipe, do **Guará Ouvidoria**, uma ferramenta de ouvidoria inteligente criada durante o evento **Piauí para o Mundo**.

O projeto buscou aplicar tecnologia para melhorar o recebimento, organização e tratamento de manifestações em sistemas de ouvidoria.

**Tecnologias e conceitos:**

`Desenvolvimento Web` `Inteligência Artificial` `Trabalho em Equipe` `Prototipação` `APIs`
